# 🍔 Zomato AI Recommender - Live App

Click the link below to open and test the running recommendation application instantly in your browser (no deployment, setup, or API key configuration required):

---

### Features to Try:
*   **State & City Selection (Generative Search)**: Select `Delhi` ➔ `New Delhi` or `Maharashtra` ➔ `Mumbai` to see the AI suggest real-world restaurants from its own pre-trained knowledge base.
*   **Bangalore Database Mode**: Select `Karnataka` ➔ `Bangalore` to filter through 12,000+ local restaurants.
*   **Search Preferences & Filters**: Set Cuisine, Budget, Rating, and type custom preferences (like *"rooftop seating"* or *"romantic date night"*) directly on the main page.
*   **AI Insight explanations**: View the personalized recommendations and tailored explanations generated for each restaurant card.
